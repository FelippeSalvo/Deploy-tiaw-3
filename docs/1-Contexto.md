# 1. Introdução

Nesta seção, você vai apresentar **o contexto e a motivação do seu projeto**, explicando o problema que ele resolve, o que pretende alcançar e para quem ele é útil.

---

## 1.1 Problema  
- Descreva **claramente** o problema que o sistema vai resolver.  
- Muitas pessoas que desejam montar ou atualizar um computador encontram dificuldades para verificar a compatibilidade entre diferentes peças de hardware, como processadores, placas-mãe, memórias RAM, placas de vídeo e fontes de alimentação. A falta de conhecimento técnico ou de ferramentas simples para realizar essa verificação pode levar à escolha de componentes incompatíveis, resultando em perda de tempo, gastos desnecessários e dificuldades durante a montagem do computador.

- Além disso, as especificações técnicas de hardware podem ser complexas para usuários iniciantes, tornando difícil identificar se determinadas peças funcionam corretamente juntas. Dessa forma, surge a necessidade de uma aplicação web que facilite a verificação de compatibilidade entre componentes de computador de forma clara, simples e acessível.

---

## 1.2 Objetivos  
Defina o **objetivo geral** (o que o projeto como um todo pretende) e pelo menos **2 objetivos específicos** (detalhes ou etapas importantes).

Desenvolver um sistema web interativo que permita aos usuários verificar a compatibilidade entre diferentes peças de computador antes da montagem ou compra dos componentes.

- Implementar um sistema de seleção de componentes de hardware, como processador, placa-mãe, memória RAM, placa de vídeo e fonte de alimentação.
- Criar um mecanismo de validação automática que identifique incompatibilidades entre os componentes selecionados.
- Exibir alertas ou mensagens informando ao usuário quando houver conflitos entre as peças escolhidas.
- Desenvolver uma interface simples e intuitiva que facilite o uso da plataforma por usuários com diferentes níveis de conhecimento em informática.

---

## 1.3 Justificativa  
Explique **por que** vale a pena desenvolver este projeto.  
- A montagem de computadores personalizados tem se tornado cada vez mais comum, especialmente entre estudantes, profissionais de tecnologia, gamers e entusiastas de hardware. No entanto, muitas pessoas ainda enfrentam dificuldades para compreender as especificações técnicas dos componentes e identificar quais peças são compatíveis entre si.
- Diante desse cenário, o desenvolvimento de uma ferramenta que auxilie na verificação de compatibilidade entre peças pode ajudar usuários a tomar decisões mais seguras antes de realizar a compra dos componentes. A proposta busca oferecer uma solução simples e acessível, que reduza erros na escolha de hardware e facilite o processo de planejamento e montagem de computadores personalizados.  

---

## 1.4 Público-Alvo  
Descreva quem vai usar a solução.  

- O público-alvo do sistema são pessoas interessadas em montar ou atualizar computadores, como estudantes de tecnologia, gamers, entusiastas de hardware e usuários que desejam montar um computador personalizado.
- Esses usuários geralmente possuem conhecimentos básicos ou intermediários de informática e utilizam a internet para pesquisar peças e montar configurações de computadores. A plataforma será acessada por meio de navegadores web em computadores ou dispositivos móveis, oferecendo uma forma simples e rápida de verificar a compatibilidade entre os componentes antes da compra ou montagem do computador.
